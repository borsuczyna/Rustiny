# Unity compatibility matrix

Statuses: `SUPPORTED`, `PARTIALLY_SUPPORTED`, `CONVERTED`, `UNSUPPORTED`, `PLANNED`.
A status changes only after implementation **and** a passing test. Implemented so far: project/asset identity (Milestone 3) and reading scenes into a read-only hierarchy (first Milestone 4 slice). The engine has no import, rendering of scene content, editing or scripting layer yet.

| Unity feature | Rustiny status | Planned milestone |
|---|---|---|
| Project detection (`Assets/`, `ProjectSettings/`, `Packages/manifest.json`) | PARTIALLY_SUPPORTED: needs `Assets/` + `ProjectSettings/`, reads the editor version and whether `manifest.json` exists; package contents are not resolved. Tested on synthetic projects and one real Unity 6000.4 project | 7 |
| `.meta` / GUID preservation | PARTIALLY_SUPPORTED: GUID, format version, folder flag and importer name are read from `.meta` files; missing, broken and duplicate metas are reported; scanning never writes. Not done: generating `.meta` for new assets, importer settings, `Packages/`. Tested on synthetic projects and one real Unity 6000.4 project (27 066 metas, all parsed) | 3 |
| UnityYAML scenes/prefabs | PARTIALLY_SUPPORTED: scenes are read (streaming, read-only) for the hierarchy only: `GameObject`, `Transform`/`RectTransform`, `PrefabInstance` (one node, contents not expanded), `SceneRoots`; all other documents are skipped. Writing and `.prefab` files are not supported. Tested on synthetic scenes and one real 305 MB Unity 6000.4 scene (counts cross-checked with grep) | 7 |
| GameObject / Transform | PARTIALLY_SUPPORTED: name, active flag, layer, tag, component list (types only), local position/rotation/scale, parent/children and sibling order are read and shown in the Hierarchy and Inspector; world matrices are computed (prefab instances take their root transform from the scene's overrides) and used to place objects in the Scene view (prefab instances of `.fbx` models are drawn as the model, everything else on the GPU as boxes at their transforms; an object is drawn only while it and its parents are active). No runtime object, no editing, no component values | 4 |
| FBX models | PARTIALLY_SUPPORTED: binary FBX is read and converted to Unity conventions (Y up, left-handed, metres, `globalScale`/`useFileUnits`), one flattened mesh per file with material sections; all 9 278 files of one real project import. Not done: ASCII FBX, skins, animation, blend shapes, import settings other than scale, normals/tangent regeneration options | 5 |
| Lighting settings (`RenderSettings`, `Light`) | PARTIALLY_SUPPORTED: `RenderSettings` (fog values, ambient mode and colours, skybox material, reflection source/intensity, sun) and scene `Light` components (type, colour, intensity, range, spot angle, shadow settings, colour temperature) are read. Used: sun direction/colour/intensity, trilight/flat ambient as SH, reflection intensity, skybox material drawn as the background. Not done: ambient probe from the skybox, reflection cubemap, fog, colour temperature, lights inside prefabs, additional lights, shadows. Unit-tested; real scene judged by screenshot (ADR-0012) | 5 |
| Materials (`.mat`) | PARTIALLY_SUPPORTED: tint (`_BaseColor`/`_Color`), albedo texture (`_BaseMap`/`_MainTex`), alpha clip and cutoff, surface type, `_BumpMap`/`_BumpScale`, `_MetallicGlossMap`, `_Metallic`, `_Smoothness`/`_Glossiness`, `_EmissionColor` are read; URP Unlit is drawn unlit; matched to a model's materials by *name*, only for properties the shader declares. Not done: importer remap table, renderers' material lists, occlusion/detail/parallax maps, real transparency, any other property, custom shaders (see below) | 5 |
| Textures | PARTIALLY_SUPPORTED: PNG only (albedo as sRGB; normal and metallic-smoothness maps as linear), shrunk to 256 px, mipmapped, rows flipped to V-up. Not done: other formats (TGA, JPG, EXR, DDS), occlusion/other maps, import settings, compression | 5 |
| MonoBehaviour lifecycle, coroutines | PLANNED | 6 |
| `UnityEngine` math types | PLANNED | 6 |
| Prefab variants / nested prefabs | PARTIALLY_SUPPORTED: instances are expanded (source asset, nested prefabs, variants, `m_Modifications` of name/active/mesh/enabled/materials/local TRS, removed objects); 29 026 of 29 027 real instances, 40 of 389 979 overrides without a target. Models with several nodes are expanded into game objects with Unity's hashed fileIDs (xxHash64 of type and path), a renderer's `m_Mesh` into a model picks one mesh by its hashed ID, and material slots follow the sub-mesh order. Limits: ADR-0011 | 14 |
| `Mesh` / `Texture2D` text `.asset` | PARTIALLY_SUPPORTED: all 431 real meshes import (u16/u32 indices, uv1, tangents, colours); Texture2D uncompressed formats only (Alpha8, RGB24, RGBA32, ARGB32, BGRA32, R8, RG16), compressed formats are reported errors | 14 |
| ScriptableObject | PLANNED | 14 |
| Rigidbody / colliders | PLANNED | 9 |
| URP Lit / Unlit shaders | PARTIALLY_SUPPORTED: implemented natively in WGSL as one surface model (ADR-0009): albedo, normal map, metallic/smoothness, emission, alpha clip, unlit; Blinn-Phong lighting with one directional light (not URP's BRDF), no shadows or reflection probes | 5 |
| ShaderLab (`.shader`) | PARTIALLY_SUPPORTED: parsed (properties, sub-shaders, passes, render state, `UsePass`, pragmas); HLSL passes compile to SPIR-V with DXC and are reflected (71 of 71 on the real project, default keywords). drawn in the Scene view for HLSL passes (UniversalForward first) with default/material keywords: constant buffers filled by name, 363 of the real scene's materials (not the terrain: its meshes are serialized `.asset` meshes on prefab instances, not read yet). Camera depth/opaque textures, the skybox material, HDR output, scene sun/ambient and project globals are provided (ADR-0012). Not done: procedural instancing/storage buffers (e.g. Foliage renders black), shadows, reflection probes, post-processing, `CGPROGRAM`; unsupported or rejected shaders keep the native look; not compared with Unity | 5 |
| `CGPROGRAM` (built-in pipeline) shaders, Surface Shader | UNSUPPORTED (needs the Editor's CGIncludes and a `sampler2D` shim) | 5 |
| Shader Graph (`.shadergraph`) | UNSUPPORTED | 5 |
| `UnityEditor` API | PLANNED (partial, selected APIs) | 14 |
